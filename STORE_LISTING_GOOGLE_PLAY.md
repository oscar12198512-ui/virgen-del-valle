# Google Play — ficha principal

## Nombre
Playa Buche

## Descripción breve
Gestiona Playa Buche: pedidos, cocina, excursiones, usuarios y operaciones.

## Descripción completa
Playa Buche / Virgen del Valle es una aplicación de gestión integral para las operaciones de un establecimiento costero.

La aplicación reúne en un solo lugar herramientas para organizar el trabajo diario y coordinar diferentes áreas:

• Gestión de pedidos y comandas.
• Carta digital y pedidos asociados a la ubicación del cliente.
• Organización de cocina mediante pantalla KDS.
• Gestión de usuarios y permisos por rol.
• Control de excursiones y operaciones relacionadas.
• Administración y seguimiento de información operativa.
• Herramientas de apoyo para la gestión financiera.
• Acceso protegido para usuarios autorizados.
• Recuperación de acceso mediante correo cuando el servicio de correo está habilitado.

La aplicación está orientada al personal autorizado y a las operaciones del establecimiento. Algunas funciones requieren una cuenta o permisos específicos.

Playa Buche / Virgen del Valle está diseñada para centralizar información operativa y facilitar la coordinación entre las áreas que participan en el servicio.
